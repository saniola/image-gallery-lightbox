# Image Gallery Lightbox

A static image gallery that opens each photo in a lightbox on click.

## Features

- Renders a grid of images from a predefined list
- Clicking an image opens the full-size version in a lightbox (`basicLightbox`)

## Technology

- Vanilla JavaScript
- HTML / CSS
- basicLightbox (loaded via CDN)

## Running

Open `index.html` directly in a browser, or serve the directory with any static file server, e.g.:

```
npx serve .
```
